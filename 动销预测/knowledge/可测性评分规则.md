# 可测性评分规则

可测性表示当前历史数据对预测的支撑程度，不等同于准确率保证。实际预测可信度需要结合滚动回测误差、业务节奏、数据完整性和异常波动共同判断。

## 核心指标

系统至少关注以下指标：

- 历史月份数；
- 有效月份数；
- 缺失月份数和缺失比例；
- 零动销比例；
- 动销均值、标准差和 CV；
- ADI；
- 非零需求 CV2；
- 异常值比例；
- 季节性强度；
- 趋势强度；
- 最近完整账期；
- 最佳模型的 WAPE、sMAPE、MAE、Bias；
- 回测窗口数量；
- 回测误差稳定性。

## 评分结构

综合可测性得分由两部分组成：

```text
综合可测性得分 = 结构质量得分 * 0.45 + 回测表现得分 * 0.55
```

结构质量关注历史长度、完整性、活跃度、波动性和可解释模式。回测表现关注最佳模型误差和误差稳定性。

## 等级

| 综合得分 | 等级 |
| ---: | --- |
| >= 75 | 高可测 |
| >= 50 且 < 75 | 中可测 |
| < 50 | 低可测 |

## 风险解释

常见风险包括：

- 历史月份少于 12 个月，回测支撑不足；
- 零动销比例较高，需求可能呈现间歇性；
- CV 较高，序列波动大；
- 最佳模型 WAPE 偏高，历史回测误差较大；
- 最新月份疑似不完整；
- 季节性强度不足，季节模型可能不稳定；
- 有效月份少，存在冷启动或新品风险。
