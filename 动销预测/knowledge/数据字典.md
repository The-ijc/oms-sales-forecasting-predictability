# 数据字典

本文档说明当前 OMS 动销预测与可测性分析系统使用的数据字段和预测粒度。知识库只存放口径说明，不存放数据库文件、客户明细或真实业务结果。

## 数据表

当前系统读取本地 SQLite 表：

```text
adb_model_sales_summary
```

应用以只读方式访问数据库，并按月度和业务维度做聚合分析。

## 字段映射

| 业务含义 | 数据库字段 | 用途 |
| --- | --- | --- |
| 账期 / 月份 | `fin_year_month` | 时间序列月份字段 |
| 渠道大类 | `channel` | 第一层预测粒度和筛选字段 |
| 渠道细分类 | `channel_` | 第二层预测粒度和筛选字段 |
| 型号 | `product_model` | 第三层预测粒度和筛选字段 |
| 品类 | `product_category` | 辅助业务字段，当前不直接进入预测序列 |
| 细分品类 | `product_class` | 辅助业务字段，当前不直接进入预测序列 |
| 动销数量 | `qty_total` | 当前预测目标字段 |

## 三层预测粒度

1. 渠道大类：按 `channel + fin_year_month` 聚合 `qty_total`。
2. 渠道细分类：按 `channel + channel_ + fin_year_month` 聚合 `qty_total`。
3. 渠道型号：按 `channel + channel_ + product_model + fin_year_month` 聚合 `qty_total`。

系统只输出聚合后的预测结果、回测指标和可测性证据，不输出原始客户明细或交易明细。
