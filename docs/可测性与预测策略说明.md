# 可测性与预测策略说明

## 1. 数据口径

应用读取 SQLite 表 `adb_model_sales_summary`，字段映射如下：

| 业务含义 | 字段 |
| --- | --- |
| 时间字段 | `fin_year_month` |
| 渠道大类 | `channel` |
| 渠道细分类 | `channel_` |
| 型号 | `product_model` |
| 品类 | `product_category` |
| 细分类 | `product_class` |
| 动销预测目标 | `qty_total` |

当前以 qty_total 作为动销数量口径，最终项目交付前需要与业务方确认该字段是否与动销定义完全一致。

## 2. 预测粒度

应用支持三种层级：

1. 渠道大类预测：`channel + fin_year_month`。
2. 渠道细分类预测：`channel + channel_ + fin_year_month`。
3. 渠道型号预测：`channel + channel_ + product_model + fin_year_month`。

所有读取均使用 SQL 聚合，不读取客户维度，也不展示原始交易明细。渠道型号层级默认只取筛选条件下总动销最高的前 50 个对象。

## 3. 候选算法

已实现算法：

| 算法 | 说明 |
| --- | --- |
| Naive 最近值 | 未来值等于最近一个完整月份。 |
| 三期移动平均 | 未来值等于最近 3 期均值。 |
| SES | 简单指数平滑，默认 `alpha=0.35`。 |
| Holt 线性趋势 | 水平项和趋势项指数平滑。 |
| 线性回归趋势 | 用时间序号拟合一元线性趋势。 |
| Seasonal Naive | 使用 12 个月前同月作为预测。 |
| Random Forest 滞后特征 | 使用最近 1/2/3 期、三期均值、月份位置作为特征的轻量随机森林。 |
| Croston SBA | 适合高零值或间歇性需求序列。 |

额外保守策略包括历史均值和零预测，仅用于历史很短或降级兜底。

## 4. 候选模型纳入规则

阈值集中定义在 `src/utils.py`：

| 常量 | 默认值 | 含义 |
| --- | ---: | --- |
| `SHORT_HISTORY_MONTHS` | 6 | 历史不足 6 个月时只允许保守策略。 |
| `MIN_TRAIN_PERIODS` | 12 | 默认最少训练期。 |
| `DEFAULT_BACKTEST_WINDOWS` | 6 | 默认回测窗口。 |
| `ZERO_RATIO_HIGH` | 0.50 | 零值比例达到 50% 视为高零值。 |
| `ADI_INTERMITTENT` | 1.32 | ADI 达到 1.32 视为间歇性需求倾向。 |
| `SEASONAL_MIN_MONTHS` | 24 | 至少 24 个月才检查季节模型。 |
| `SEASONAL_STRENGTH_THRESHOLD` | 0.30 | 季节性强度达到 0.30 纳入 Seasonal Naive。 |
| `RANDOM_FOREST_MIN_MONTHS` | 24 | Random Forest 至少需要 24 个月历史。 |
| `RANDOM_FOREST_MIN_NONZERO` | 12 | Random Forest 至少需要 12 个非零样本。 |

规则：

* 历史不足 6 个月：只允许 Naive、历史均值、零预测等保守策略。
* 零值比例较高或 ADI 较高：纳入 Croston SBA。
* 历史不少于 24 个月且季节性强度明显：纳入 Seasonal Naive。
* 历史长度和非零样本数足够：纳入 Random Forest。
* 模型训练失败：记录原因，并降级到 Naive；若序列为空，则降级到零预测。

## 5. 滚动回测与模型选择

Walk-Forward 回测流程：

1. 按月份升序排列序列。
2. 自动排除疑似最新不完整月份。
3. 从满足最少训练期的位置开始，每次只用历史数据预测下一个月。
4. 默认回测最近 6 个完整月份。
5. 不随机打乱时间顺序。

评价指标：

* WAPE：主指标，`sum(abs(actual - pred)) / sum(abs(actual))`。
* sMAPE：辅助指标。
* MAE：绝对误差均值。
* Bias：预测偏差，默认按真实值绝对总和归一化；真实值总和为 0 时使用平均偏差。

选择规则：

1. 优先选择主指标最低的模型。
2. 若 WAPE 无法计算，例如真实值总和为 0，则使用 MAE 作为主指标。
3. 若主指标差异在 `WAPE_TIE_TOLERANCE = 0.03` 范围内，比较 sMAPE。
4. 若 sMAPE 差异也在 `SMAPE_TIE_TOLERANCE = 0.03` 范围内，选择更简单、更稳定的模型。

## 6. 最新月份不完整判断

最新月份是否不完整使用启发式判断：

* 若最新月份全库记录数低于前三个月中位数的 50%，提示不完整风险。
* 若最新月份全库动销量低于前三个月中位数的 `INCOMPLETE_LATEST_RATIO = 0.35`，提示不完整风险。
* 单个序列也会检查最新月份动销量是否显著低于前三个月中位数。

该判断不替代业务入库状态确认，只用于避免把明显未完结月份放入训练和回测。

## 7. 可测性指标

每个序列至少计算：

* 历史月份数；
* 有效月份数；
* 缺失月份数及比例；
* 零动销比例；
* 动销均值、标准差、CV；
* ADI；
* 非零需求 CV²；
* 异常值比例；
* 季节性强度；
* 趋势强度；
* 最近完整月份；
* 最佳模型的 WAPE、sMAPE、MAE、Bias；
* 回测窗口数量；
* 不同回测窗口的误差稳定性。

## 8. 得分组成

综合可测性得分由两部分组成：

```text
综合可测性得分 = 结构质量得分 * 0.45 + 回测表现得分 * 0.55
```

权重常量：

| 常量 | 默认值 |
| --- | ---: |
| `STRUCTURE_WEIGHT` | 0.45 |
| `BACKTEST_WEIGHT` | 0.55 |

结构质量得分满分 100，组成如下：

| 子项 | 分值 | 逻辑 |
| --- | ---: | --- |
| 历史长度 | 25 | 24 个月及以上满分，不足时按比例给分。 |
| 完整性 | 20 | `1 - 缺失比例`。 |
| 活跃度 | 20 | `1 - 零值比例`。 |
| 波动性 | 20 | CV 越低得分越高。 |
| 可解释模式 | 15 | 季节性或趋势越明显，得分越高。 |

回测表现得分满分 100：

| 子项 | 权重 | 逻辑 |
| --- | ---: | --- |
| 误差得分 | 80% | 根据 WAPE 或 MAE 相对均值分段给分。 |
| 稳定性得分 | 20% | 回测窗口误差越稳定，得分越高。 |

误差得分分段：

| WAPE 或替代误差 | 得分 |
| --- | ---: |
| <= 20% | 100 |
| <= 35% | 85 |
| <= 50% | 70 |
| <= 80% | 50 |
| <= 120% | 30 |
| > 120% | 15 |

等级阈值：

| 综合得分 | 等级 |
| ---: | --- |
| >= 75 | 高可测 |
| >= 50 且 < 75 | 中可测 |
| < 50 | 低可测 |

可测性表示当前数据对预测的支撑程度，不保证实际准确率。实际预测可信度应结合滚动回测误差、业务场景、最新数据完整性和异常波动共同判断。
