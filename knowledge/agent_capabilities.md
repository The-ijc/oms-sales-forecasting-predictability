# 智能分析助手能力边界

## 当前可以回答

Agent 可以通过业务工具查询当前筛选对象的动销预测结果、候选模型比较、可测性证据和风险提示；也可以通过知识工具检索指标定义、预测方法说明、项目业务规则、数据口径和操作边界。

## 当前业务工具

- `get_forecast_result`：返回当前筛选对象的预测账期、预测值、经验预测区间、最优模型和最近完整账期。
- `get_model_comparison`：返回候选模型启用状态、回测指标、排名和模型选择说明。
- `get_predictability_evidence`：返回可测性得分、数据质量指标、回测 WAPE、风险提示和证据列表。
- `search_knowledge_base`：检索项目内 Markdown 知识片段，不读取 SQLite 业务数据。

## 当前不能回答

当前工具不能查询精确的历史实际销量明细、客户或交易明细、实时库存、补货数量、价格、促销执行状态，也不能写入数据库。知识工具不能替代业务工具生成当前销量、预测值、模型结果或可测性计算结果。

## 工具路由原则

涉及当前筛选对象的销量、预测值、模型结果、可测性得分或风险指标时使用业务工具。涉及指标含义、业务规则、方法说明、数据口径、操作说明或项目文档时使用知识工具。问题同时包含业务结果和知识解释时，可以组合调用两类工具，并分别引用对应 Observation。
