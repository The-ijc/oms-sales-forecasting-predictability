# 动销预测指标词汇

以下定义来自当前项目代码与《可测性与预测策略说明》。其中阈值属于项目内部计算或模型启用规则，不代表行业 benchmark。

## WAPE

WAPE 是滚动回测的主比较指标，计算为 `sum(abs(actual - predicted)) / sum(abs(actual))`。真实值绝对值总和为 0 时，WAPE 不可计算，项目改用 MAE 参与模型比较。WAPE 是聚合回测误差指标，不能直接解释为某个单点预测的正负误差区间。

## CV

CV 是变异系数，当前项目按序列总体标准差除以动销均值的绝对值计算。CV 用于描述序列相对波动程度；项目的可测性结构得分中，CV 越低，波动性得分越高。

## ADI

ADI 是平均需求间隔，当前项目按序列期数除以非零需求期数计算。没有非零需求时 ADI 为无穷大。项目内部使用 `ADI >= 1.32` 识别间歇性需求倾向，该值不是行业评级承诺。

## 季节性强度

当前项目按 12 个月季节位置分别计算均值，再用这些季节均值的标准差除以全序列标准差，结果限制在 0 到 1。历史不足 24 个月时季节性强度返回 0。项目内部在历史不少于 24 个月且季节性强度达到 0.30 时考虑 Seasonal Naive。

## 趋势强度

趋势强度是时间序号对动销序列进行一元线性拟合得到的 R²，结果限制在 0 到 1。它描述当前序列被线性趋势解释的程度，不代表趋势会在未来持续。

## 经验预测区间

经验预测区间由最佳模型滚动回测残差的 10% 和 90% 分位数叠加到点预测上形成，下界不低于 0。回测折数少于 3 时不提供区间。该区间是历史残差形成的经验范围，不是置信区间，也不代表准确率保证。
